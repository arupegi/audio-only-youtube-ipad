# Audio Only YouTube for iPad - Codemagic

Version 0.6.0 adds stronger seek-preview suppression.

- Blocks YouTube storyboard image URLs (`*.ytimg.com/sb/`)
- Hides seek-bar thumbnail/preview UI
- Clears dynamically inserted storyboard image sources
- Keeps audio-only and data-saver behavior from the previous version

Build with Codemagic using `codemagic.yaml`.
